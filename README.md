# Kopi Senja — Coffee Shop Landing Page

Landing page modern untuk coffee shop dengan konsep warm, minimal,
dan editorial.

## Preview

Website ini dibuat sebagai portfolio project untuk menunjukkan kemampuan
dalam membuat website landing page untuk UMKM.

## Features

- Responsive design
- Modern landing page
- Mobile friendly
- Smooth scrolling
- Scroll reveal animation
- Sticky navbar
- WhatsApp CTA
- Coffee menu section
- About & experience section
- Contact section

## Tech Stack

- HTML5
- CSS3
- JavaScript
- Google Fonts
- GitHub Pages

## Sections

- Hero
- About
- Features
- Experience
- Menu
- Quote
- Contact
- Footer

## Project Purpose

Project ini dibuat sebagai contoh landing page yang dapat
dikembangkan untuk kebutuhan website UMKM seperti coffee shop,
restaurant, barbershop, clothing brand, dan bisnis lokal lainnya.
